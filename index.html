Understanding SI Concepts in AM

To effectively apply SI in additive manufacturing, it's important to understand how different SI concepts relate to each other:

Foundation Models

A large-scale, general-purpose SI model pre-trained on massive and diverse datasets using heavy computing resources. It serves as a foundation that can be adapted or fine-tuned for many downstream tasks (generation, classification, search, reasoning). Includes LLMs, vision, audio, and multimodal models.

Generative SI Models

An SI model that creates new content — text, images, audio, video, or code — rather than only classifying or predicting. Most modern generative SI is built on top of foundation models, but smaller standalone generative models (e.g., early GANs) also exist.

Agentic SI

An SI system that autonomously plans, reasons, and executes multi-step tasks to achieve goals. It uses a generative/foundation model as its reasoning engine, but adds tool use, memory, and decision-making loops so it can act in real environments, not just produce content.

How They Work Together: Foundation models provide the underlying capabilities. Generative SI models build upon these to create new AM-specific content. Agentic SI systems use both foundation and generative models to autonomously perform complex manufacturing tasks.
