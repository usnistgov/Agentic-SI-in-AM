# SI in Additive Manufacturing

An educational platform for understanding and implementing SI in manufacturing and 3D printing.

## Overview

This repository houses an educational platform designed to bridge the domains of Additive Manufacturing (AM) and Super Intelligence (SI). The platform serves as a comprehensive resource for AM professionals, researchers, engineers, and educators looking to leverage the power of SI technologies, including generative SI, in their manufacturing workflows.

## Main Sections

- **Introduction to SI in AM** - Foundational concepts and terminology
- **Develop SI Models for AM** - Step-by-step implementation guides
- **SI Agents in AM** - Applications of autonomous SI systems
- **Resource Repository** - Datasets, tools, and learning materials
- **Miscellaneous Projects** - Additional research and applications

## Features

- Responsive design for all devices
- Integrated search functionality
- Content depth indicators (beginner/intermediate/advanced)
- Structured learning paths
- Interactive navigation with breadcrumbs and table of contents

## NIST Pages Deployment

Target website: **https://pages.nist.gov/Agentic-SI-in-AM/**

Publish this project through NIST's Pages infrastructure with the project/repository name `Agentic-SI-in-AM` and `index.html` in the published root. The URL is controlled by the NIST Pages hosting configuration, not by the HTML title or canonical tag. If publishing through a GitHub mirror, confirm that the NIST Pages service is connected to that repository and that the output is deployed to the project path `/Agentic-SI-in-AM/`.

The website uses relative links to accommodate the project path. The `<link rel="canonical">` and Open Graph URL metadata identify the intended public location; they do not configure deployment.

## Getting Started

1. Clone the repository:

   ```bash
   cd Agentic-SI-in-AM
   ```

2. View the site locally:
   - Open `index.html` in your browser
   - Or use a local server: `python -m http.server`
