# Deployment instructions

Publish contents of this archive at the root of the `nist-pages` branch of `usnistgov/Agentic-SI-in-AM`. Do not upload the ZIP itself or nest the extracted folder. Replace existing files.

Expected target: https://pages.nist.gov/Agentic-SI-in-AM/index.html

Navigation is consistent across all pages with `.navbar` and directory names with spaces are URL-encoded.

If the live site does not reflect updates, check whether the new commit is on `nist-pages`, refresh with Ctrl+Shift+R, and compare view-source with GitHub.
